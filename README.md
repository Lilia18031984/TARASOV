# Random Task Generator - Генератор случайных задач

**Автор:** Матвей Тарасов

## 📝 Описание

Random Task Generator - это графическое приложение для генерации случайных задач на день. Помогает разнообразить повседневные дела, добавляя элемент случайности и геймификации в выполнение рутинных задач. Позволяет создавать свою библиотеку задач, отслеживать историю выполненных задач и фильтровать их по типу.

## ✨ Основные возможности

- 🎲 Генерация случайных задач из библиотеки
- ✅ Отметка задач как выполненных с сохранением в историю
- 📜 История всех выполненных задач
- 🔍 Фильтрация истории по типу задачи
- ➕ Добавление новых задач в библиотеку
- ✏️ Управление задачами (просмотр, удаление)
- 💾 Автоматическое сохранение данных в JSON
- 🗑 Очистка истории
- 💿 Экспорт истории в JSON файл
- 🎯 Предустановленная библиотека из 20 задач
