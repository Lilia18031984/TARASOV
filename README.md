# Random Password Generator - Генератор случайных паролей

**Автор:** Матвей Тарасов

## 📝 Описание

Random Password Generator - это графическое приложение для генерации надёжных случайных паролей с возможностью настройки параметров, оценки сложности и сохранения истории сгенерированных паролей.

## ✨ Основные возможности

- 🔐 Генерация случайных паролей с настраиваемыми параметрами
- 📏 Регулировка длины пароля (от 4 до 32 символов)
- 🔤 Выбор типов символов (строчные, заглавные буквы, цифры, спецсимволы)
- 📊 Оценка сложности пароля (низкий, средний, высокий, очень высокий)
- 📋 Копирование пароля в буфер обмена
- 📜 История всех сгенерированных паролей
- 💾 Автоматическое сохранение истории в JSON
- 🗑 Очистка истории
- 💿 Экспорт истории в JSON файл
- 🔒 Маскирование паролей в истории для безопасности
